TwemojiMozilla-COLR-subset.ttf
==============================

Provenance
----------

Upstream:  Twemoji Mozilla v0.7.0 (Twemoji.Mozilla.ttf, 1474284 bytes,
           md5 aac75d901445bc0419d56e56dbc18891)
Source:    https://github.com/mozilla/twemoji-colr
           https://github.com/mozilla/twemoji-colr/releases/download/v0.7.0/Twemoji.Mozilla.ttf

Subset to four emoji (U+2764 heart, U+1F308 rainbow, U+1F525 fire,
U+1F680 rocket) so the repository carries 2 KB instead of 1.4 MB, with
fontTools 4.46.0:

    python3 -m fontTools.subset Twemoji.Mozilla.ttf \
        --unicodes=U+1F680,U+1F525,U+2764,U+1F308 \
        --name-IDs='*' --drop-tables+=FFTM \
        --output-file=TwemojiMozilla-COLR-subset.ttf

Nothing else was changed: the family name is still "Twemoji Mozilla", the
COLR table is still version 0 (20 glyphs, 4 base glyphs, 15 layers) and
CPAL still holds one palette of 13 colors. It is here as the renderer's
COLRv0 test font — layer enumeration, palette resolution and layer draw
order are asserted against it — and as the vector color glyph in
`examples/offscreen`.
